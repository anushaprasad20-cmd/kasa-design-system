Usage

  • The footer must appear at the bottom of every page.
  • The two-band structure must be preserved: Charcoal main band, Forest Green copyright strip.
  • Column headers (Explore, Visit, Contact) use Label style — uppercase, muted, small tracking.
  • The KASA wordmark in the footer must link to the homepage.
  • Social icons must include aria-label attributes for screen readers.
  • Footer links should have a visible hover state — Amber #E9901E on hover.

Accessibility Considerations

All footer text uses White #FFFFFF on Charcoal #1E1E1A, achieving 16.1:1 contrast. The copyright strip uses White on Forest Green #0C3D2E at 10.8:1. Both exceed WCAG AA and AAA requirements. Social icon links must have descriptive aria-label attributes since they contain no visible text.

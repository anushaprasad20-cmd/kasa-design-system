Code

navbar.html 
<nav class="navbar navbar-expand-lg navbar-dark sticky-top"
     style="background-color: #1E1E1A;">
  <div class="container-fluid px-4">
    <a class="navbar-brand fw-bold" href="index.html"

      KASA
    </a>
    <button class="navbar-toggler" type="button"
      data-bs-toggle="collapse" data-bs-target="#navbarNav"
      aria-controls="navbarNav" aria-expanded="false"
      aria-label="Toggle navigation">
      <span class="navbar-toggler-icon"></span>

             style="color: #E9901E; font-family: 'Anek Latin', sans-serif;">
            Home
          </a>
        </li>
        <li class="nav-item">
          <a class="nav-link" href="menu.html"
             style="color: #FFFFFF; font-family: 'Anek Latin', sans-serif;">
            Menu
          </a>
        </li>
        <li class="nav-item">

            Reserve a table
          </a>
        </li>
      </ul>
    </div>
  </div>
</nav>

Usage

  • The navigation bar must appear on all pages.
  • The wordmark KASA must always link to the homepage.
  • The active page link is highlighted in Amber #E9901E, SemiBold weight.
  • The Reserve a table CTA button must always be visible in the navbar.
  • The navbar must remain sticky at the top of the viewport on scroll.
  • On mobile, the nav collapses into a hamburger menu.

Accessibility Considerations

This navbar uses White and Amber text on a Charcoal #1E1E1A background. White on Charcoal achieves 16.1:1 contrast — well above the WCAG AA requirement of 4.5:1. Amber on Charcoal achieves 6.8:1, meeting AA for all text sizes. The “Reserve a table” button uses White text on Amber fill at 3.1:1 — ensure the button text remains at least 18px or bold to meet WCAG AA for large text.

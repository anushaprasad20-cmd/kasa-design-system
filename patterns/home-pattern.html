Layout Notes

  • Max content width: 1280px, centered with horizontal padding.
  • Hero section: minimum 400px tall, content left-aligned and vertically centered.
  • About section: 50/50 two-column grid, image left, text right.
  • Menu cards: 4-column grid (CSS Grid or Bootstrap row), gap between cards: 1rem.
  • Find Us section: 60/40 split — info left, map right.
  • CTA band: flexbox row, space-between alignment.
  • All sections use at least 3rem vertical padding.

Logo Variations

The Kasa wordmark in four forms. Each variation has a specific context, choosing the right one keeps the mark legible and on-brand across every surface.

Color
Primary

The color logo is the primary logo and should be used against light backgrounds.

Grayscale

The grayscale logo should be used when printing in color is not an option.

Color Inversed

The color inversed logo should be used against dark backgrounds to ensure legibility.

Favicon

The favicon logo uses just the “K” monogram, sized for a browser tab next to the page title.
